Question Progression
--------------------------------------------------

Easy Questions

• Definition

• Purpose

• Basic Concepts

• Differences

Examples

"What is Python?"

"What is REST API?"

"What is supervised learning?"

--------------------------------------------------

Medium Questions

• Implementation

• Practical Usage

• Code Behaviour

• Real Project Usage

Examples

"How would you implement authentication in FastAPI?"

--------------------------------------------------

Hard Questions

• Scenario

• Optimization

• Debugging

• Scalability

Examples

"How would you debug memory leaks in this service?"
